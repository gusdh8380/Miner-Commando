>

## 개요

황폐화된 지구를 떠나 제2의 지구를 찾아 떠나는 과정에서, 생존을 위한 타 행성 자원 채굴 임무를 수행하는 탑다운뷰 멀티플레이 픽셀아트 2D 게임입니다.

## 게임 설명

우주모함에서 임무를 받고 탐사선에 탑승하여 출동합니다. 하나의 공유 오브젝트 **탐사선**을 4명의 플레이어가 함께 조종하며 자원을 채굴합니다.

- 자원 채굴 과정에서 몬스터의 위협과 환경의 방해를 헤쳐나가야 합니다.
- 상호작용 키 `F`로 모듈에 탑승/사용할 수 있으며, 자원 채굴과 드랍된 자원을 인벤토리로 파밍할 수 있습니다.
- 모듈 탑승 시 해당 모듈에 맞게 키가 변경됩니다. (예: 공격모듈 탑승 시 `Space`로 공격, 방향키로 공격 방향 전환)
- 모듈에서 벗어나려면 `F`를 다시 누르면 됩니다.

### 탐사선 모듈

| 모듈 | 설명 |
|------|------|
| 운전석 | 탐사선의 이동을 담당 |
| 공격모듈 | 탐사선에서 공격 수행 |
| 특수탄약칸 | 공격모듈의 특수공격 탄약 충전 |
| 특수탄약고 | 플레이어에게 특수탄 제공 (상호작용 시 1발 획득 → 특수탄약칸에서 장전) |
| 창고 | 채굴한 자원 저장 (일정량 달성 시 미션 클리어 후 모함 귀환) |
| 전력칸 | 탐사선 유틸 기능 담당 (환경 적응 기능 탑재) |
| 출입구 | 탐사선 내외부 이동 |

## 기여 및 역할

- 게임 시작 씬 개발 (매치메이킹 및 채팅 기능)
- 게임 로비 개발 (채팅, 출동 기능, UI, 임무 부여)
- 게임 플레이 오브젝트 네트워크 동기화 구현
- 로딩 씬 및 엔딩 씬 개발

## 도전 과제

### 1. 플레이어가 함께 조종하는 탐사선 구현

- 상속을 통한 각 모듈(조종석) 구현
- 모듈 동시 조종 시 각 모듈은 독립적으로 작동하되 동기화 유지

### 2. 창고 동기화

- 모든 플레이어가 공유하는 인벤토리를 `OnPhotonSerializeView`로 실시간 관찰 및 결과 동기화

### 3. 게임 시작 씬 구현

- 전용 서버 입장을 통한 룸 생성 후, 호스트-클라이언트 방식(리슨 서버)으로 전환
- 4인 팀 구성 → 방장(호스트)이 게임 시작 → 로딩 씬 → 게임 로비
- 채팅 기능 구현

### 4. 게임 로비 씬 구현

- 스토리/임무 부여 및 행성 탐사 출동을 위한 로비 씬
- 채팅 기능 구현

### 5. 비동기 씬 로딩 (미해결)

- 비동기 호출로 구현 시도했으나, 게임 입장 시 플레이어 생성 버그를 해결하지 못해 `PhotonNetwork.LoadLevel()`로 대체
